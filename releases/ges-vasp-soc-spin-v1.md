# GeS VASP SOC Spin Runtime Data v1

Optional data for the GeS spin-current and Zeeman-geometry tutorials.

## Included files

- `GeS.spn`: spin matrix elements.
- `GeS.chk`: Wannier checkpoint.
- `GeS.eig`: eigenvalues.
- `GeS.mmn`: overlap matrices.

## Getting started

Download `GeS_vasp_SOC_spin_runtime_v1.tar.gz` from this release and follow the optional spin-data instructions in the tutorial repository. Use the dataset with its matching GeS model and Wannier conventions; matching filenames alone do not guarantee compatibility.

## Notes on the data

This is the dataset associated with the earlier GeS examples. It is separate from the unified Fe and GeS datasets prepared for Tutorials 1.2.

See the file inventory and checksum list for verification and provenance.
